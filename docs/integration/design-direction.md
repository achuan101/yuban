# 语伴 × Alex 的融合设计

设计依据：用户确认的850词范围、保守定位、生活场景、听说读写闭环；Anthropic `skills/frontend-design` 的官方设计指导。本地原系统来源为 `02_UI_Agent/site`，目标仓库为 `achuan101/yuban`。

## 视觉方案

白 `#fbfdfc` 为主，墨绿 `#163c31` 为正文与导航，青绿 `#158765` 为主要操作，雾绿 `#e8f3ed` 为选择反馈，蓝 `#648bb9` 为场景与次要提示。字体采用系统中文无衬线与英文 Georgia 阅读字体，无外部字体请求。首页左侧呈现明确的学习意图，右侧是可以试听、翻译、点击单词的真实小课程。只有场景背景参与轻微视差，遵守 reduced-motion 设置。

```
品牌 / 导航                             继续学习
把英语变成自己的话          可操作的家庭场景图
入学测 / Alex陪练           英文 / 翻译 / 听示例
简单解释学习闭环            熟悉词为主，少量新词
```

学习页用大幅可复用SVG场景配图承载理解，上方短/中/长文章与难度选择，下方阅读和内嵌练习面板。全文/逐句切换复用同一录音、回听和听写工具，避免重复弹窗和每句话一排按钮。单词解释展开在当前句下方。

## 数据与功能

保留 yuban 的 Vue/Router/Pinia 结构。用本地项目850词库和测评引擎替换原40词演示库，不把小样本识读范围当CEFR或总英语词汇量。测评始终使用同一个 item_id 生成题面、选项、判分及反馈，记录答对、答错、明确不会、未测；后续学习证据与初步估计分开。

首篇推荐围绕可信区间下界和已识读词，优先补真实缺口；不能以“排到300”声称前300个逐词掌握。场景横向轮换，重复遇到的目标词跨场景巩固。点击词表示需要支持，没点击不自动表示掌握。朗读识别只能给文本匹配分，未接专业测评服务时不伪装为发音评分。只听完或只跟读不算主动使用。

DeepSeek由同源服务端调用，密钥只从服务器环境读取。豆包声音/实时语音和专业发音测评是需要账户开通的独立能力，未配置时明确说明。迁移读取原alex850Model及yuban-learner-v1；换域名需要导出导入学习档案。保留原项目供回退。
