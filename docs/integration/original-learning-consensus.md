# V1 总体任务：850词可理解输入—输出闭环

## 冻结范围

- 入学测只估算用户提供的 Ogden 850 词范围，不再显示 6,800、8,000 或 10,000 词。
- 原表结构完整保留：100个操作与关系词、400个一般事物、200个可图示事物、100个一般性质、50个相对性质。
- 采用方案B：保留每个词的原始分类与位置，同时按儿童句子组合价值和已有课程序重排为8个100词级与最后1个50词级。
- 测评记录答对、答错、明确不会、未直接抽测四类状态；最终只给850范围内的估计值与区间。

## 学习闭环

每个单元遵循：

1. 明确一个可完成的真实输出目标；
2. 用图片/轻动画、声音和 Easy English 建立可理解输入；
3. 从整体理解进入模仿、替换、引导复述和独立表达；
4. 从朗读、复述和听写中捕捉具体输出缺口；
5. 下一篇优先用新场景补足缺口，而不是重复推送已经稳定掌握的词。

850词入学测只决定输入起点，不把识读等同于主动使用。词汇状态依次记录：未测、明确不会、学习中、阅读识别、听力识别、发音可用、听写可用、主动调用、跨场景稳定。

## 分级输出

- 约100—150词：指图、跟读、补一个词；
- 约200—300词：替换人物或物品说一句；
- 约300—500词：看图回答并复述2—3句；
- 约500—700词：根据提示介绍一个场景；
- 接近850词：连续表达和角色对话。

输出评价分开显示完整度、准确度、流利度和节奏。发音分不反向降低词义识读估计。

## 低成本媒体策略

- 默认文章路径不调用图片或视频生成API；
- 浏览器用复用场景符号和轻动效即时呈现，无额外等待和单次生成成本；
- DeepSeek只负责按用户估计已知词、目标词、输出目标和历史缺口生成文章；
- AI失败时立即使用本地可理解内容，不阻断学习；
- 语音播放和录音优先使用浏览器能力；没有识别能力时保留录音回听，但不伪造分数。

## V1 验收

- 850词条完整且 item_id、显示词、正确答案、反馈一致；
- 自适应题目不重复，包含“我不会”；
- 结果显示估计区间并区分实际抽测与未抽测；
- 不同估计水平获得不同文章长度和输出方式；
- 文章所有英文词可点击，全文翻译统一开关；
- 只有五个固定学习入口，不在每句下面重复按钮；
- 支持整篇/逐句朗读、录音回听、浏览器初评和自适应听写；
- 输出缺口进入下一篇文章生成参数；
- Alex完成一次页面引导后保持安静；
- DeepSeek密钥只保存在服务端环境变量中。
