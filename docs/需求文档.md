## 1. 产品概述

### 1.1 产品定位

「语伴」是一款面向英语学习者的**陪伴式 AI 语伴**产品。AI 的认知水平与英语能力与学生当前水平**一致或略高**，通过语音/视频对话进行沉浸式练习，并在必要时用图像、短视频辅助理解抽象或难懂概念，帮助学生持续提升英语能力。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 水平匹配 | AI 用词、语速、话题难度贴近学生真实水平，降低挫败感 |
| 陪伴练习 | 以自然对话为主，而非题海刷题，提升开口意愿与持续使用 |
| 动态调适 | 入学测定基线，后续用交互数据持续校准画像 |
| 多模态辅助 | 语音/视频为主，生图/生视频补足抽象概念理解 |

### 1.3 目标用户

- 有英语口语/听力练习需求的学生（K12、大学生、成人自学均可，首期可聚焦单一年龄段）
- 希望有固定「语伴」陪练、而非单向课程讲解的学习者

### 1.4 非目标（本期不做）

- 完整的应试刷题系统（中高考/雅思托福整卷）
- 真人外教匹配与排课
- 离线本地大模型完整部署（可后续评估）

---

## 2. 问题与目标

### 2.1 要解决的问题

1. 传统学习 App 难度固定，过易无聊、过难放弃。
2. 学生缺少安全、低压力的开口场景。
3. 纯文字/语音对抽象名词、文化概念解释成本高、理解慢。
4. 一次问卷/测验无法长期代表真实水平，需要持续更新。

### 2.2 产品目标（可度量）

| 目标 | 指标建议（可后续标定） |
|------|------------------------|
| 水平匹配准确 | 入学测后 7 日内，对话难度「过难/过易」反馈占比下降 |
| 持续使用 | 次日留存、周活、单次会话时长 |
| 理解辅助有效 | 生图/生视频触发后，学生「听懂/会用」确认率 |
| 开口量 | 学生有效口语时长、话轮数 |

## 3. 用户旅程总览

```
注册/登录
    ↓
基础信息采集（年龄、学习目标等）
    ↓
入学测试（高频词分级测评）        ← 第一步水平定义
    ↓
生成初始学习画像 + 匹配 AI 语伴人设
    ↓
语音/视频日常对话练习
    ↓
交互中：难词/抽象概念 → 生图/生视频辅助
    ↓
后台持续采集交互数据 → 动态更新水平画像
    ↓
AI 难度与话题策略同步调整
```

## 4. 功能需求

### 4.1 入口与入学测试（Placement Test）

#### 4.1.1 需求背景

仅靠年龄等简单信息无法准确定位英语水平。需要在正式陪伴对话前，通过**入学测试**完成第一步水平定义，并为后续动态评估提供基线。

#### 4.1.2 词库与分级策略

- **词库范围**：日常用语中出现频率最高的前 **500** 词（高频核心词）。
- **分级方式**：将 500 词按难度/频次区间划分为若干等级（建议 5 级，可配置），例如：

| 等级 | 大致范围（示例） | 说明 |
|------|------------------|------|
| L1 | 词频 Top 1–100 | 基础日常词 |
| L2 | 101–200 | 常见生活词 |
| L3 | 201–300 | 进阶日常词 |
| L4 | 301–400 | 稍难/场景扩展 |
| L5 | 401–500 | 相对低频但仍属高频带 |

> 具体切分阈值、词表来源（如 CEFR、词频表）需在详细设计中锁定；入学测结果映射到内部等级（如 Beginner / Elementary / Intermediate 等）。

#### 4.1.3 测试形态（建议）

采用**自适应或分阶抽题**，控制时长约 **8–15 分钟**，避免过长流失。

建议题型组合（可分期上线）：

| 题型 | 考察点 | 优先级 |
|------|--------|--------|
| 听音选义 / 看义选词 | 词汇识别 | P0 |
| 听句选关键词 | 听力中的词汇 | P0 |
| 跟读/口语产出（可选词造句） | 口语产出与发音粗测 | P1 |
| 情景选择题（短对话） | 简单语用 | P1 |

**自适应逻辑（建议）**：从中间档（如 L3）起步，答对升档、答错降档，若干题后收敛到稳定等级；未测到的等级用插值估计覆盖度。

#### 4.1.4 入学测产出

测试结束后系统应输出：

1. **词汇等级**：主等级 + 各档正确率/覆盖估计  
2. **初始 CEFR/内部等级映射**（供 AI 控词控速）  
3. **弱项标签**（如：听力弱、产出弱）  
4. **推荐首日话题包**（与等级匹配的安全话题）

用户侧展示：简洁结论（「你当前大约在 X 水平」）+ 鼓励性文案 +「开始和语伴聊天」CTA。允许「跳过测试」（需二次确认），跳过则仅用基础信息给临时等级，并在后续对话中加速校准。

#### 4.1.5 基础信息采集（与入学测配合）

入学测前或测后采集（表单尽量短）：

- 年龄/学段  
- 学习目标（考试 / 旅行 / 日常开口 / 兴趣）  
- 母语  
- 每日可练习时长（可选）  
- 偏好交互：语音为主 / 视频为主  

这些信息用于人设、话题与节奏，不单独替代入学测等级。

### 4.2 学生水平画像与动态评估

#### 4.2.1 初始画像

由「基础信息 + 入学测结果」生成初始 `Learner Profile`，至少包含：

- 词汇等级与覆盖估计  
- 听力/口语粗能力标签  
- 兴趣与目标  
- AI 输出约束：词汇表上限、句长、语速、纠错强度  

#### 4.2.2 持续校准（核心）

在语音/视频交互过程中持续采集信号，定期（如每 N 轮对话或每日）更新画像：

| 信号类型 | 示例 | 用途 |
|----------|------|------|
| 理解度 | 是否请求重复、是否触发「解释/生图」 | 下调或放慢 |
| 产出质量 | ASR 文本的词汇多样性、语法错误密度、流利度代理指标 | 上调/下调产出期望 |
| 词汇掌握 | 主动使用、正确回应、遗忘复现 | 更新词表掌握状态 |
| 情感/参与 | 会话时长、中断率、沉默时长 | 调整话题与鼓励策略 |
| 显式反馈 | 「太难了」「太简单了」 | 立即微调难度 |

**原则**：AI 能力始终维持在「持平或略高于」当前估计水平，避免长期显著超纲或显著低幼。

#### 4.2.3 水平变化可见性

- 学习报告：周维度等级变化、新掌握词、薄弱点  
- 不强制「打分羞辱」；以成长曲线与可达成小目标呈现  

---

### 4.3 核心交互：语音 / 视频聊天

#### 4.3.1 交互形态

| 模式 | 说明 | 优先级 |
|------|------|--------|
| 语音通话 | 实时或准实时双向语音对话 | P0 |
| 视频通话 | 含虚拟形象/数字人的视频陪聊（可先语音，后视频） | P1 |
| 文字兜底 | 网络差或隐私场景下可切文字 | P1 |

#### 4.3.2 对话能力要求

- 话题贴近学生等级与兴趣（日常、校园、爱好等）  
- 语速、用词受画像约束；必要时自动简化复述  
- 支持纠错策略可配置：即时轻纠 / 会话结束总结纠错  
- 鼓励多轮真实交流，而非单向讲解  

#### 4.3.3 会话流程（示意）

1. 语伴问候并提议今日话题（可学生自定义）  
2. 多轮对话；检测理解障碍与抽象概念  
3. 需要时触发多模态解释  
4. 结束时简短复盘（今日新词、一句可带走的表达）  

---

### 4.4 多模态理解辅助：生图 / 生视频

#### 4.4.1 触发场景

当对话中出现以下情况时，系统可主动或由学生触发辅助：

- 抽象名词、文化负载词、学生多次未理解的表达  
- 学生说「看不懂 / 什么意思 / 举个例子」  
- 教师策略判定：纯语言解释成本高  

#### 4.4.2 能力要求

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 生图 | 针对目标词/概念生成适合年龄的配图，附简短英文+母语释义（可配置） | P0 |
| 生视频 | 短视频/动画演示动作、过程类概念（如 recycle、photosynthesis 等） | P1 |
| 安全与适龄 | 内容过滤、儿童模式合规；禁止不适画面 | P0 |

#### 4.4.3 体验要求

- 不打断对话节奏：侧栏/浮层展示，语伴可边讲边指图  
- 生成失败时回退为「简化英文 + 母语解释 + 例句」  
- 记录该词为「需视觉辅助」标签，进入复习队列  

---

### 4.5 AI 语伴人设与匹配

- 人设：友善、有耐心、略高于学生水平的同伴（非严厉考官）  
- 可根据年龄调整语气（儿童更活泼，成人更自然）  
- 可选固定形象与称呼，增强陪伴感与连续性记忆（记住学生名字、上周话题）  

---

### 4.6 学习闭环（建议纳入一期或一期半）

| 功能 | 说明 |
|------|------|
| 会话复盘 | 新词、纠错、好用表达 |
| 弱词复习 | 入学测错词 + 对话中暴露的生词 |
| 成就/连续打卡 | 轻量激励，避免过度游戏化干扰对话 |

## 9. 产品决策（原型已落地）

| 议题 | 决策 |
|------|------|
| 首期用户 | 支持儿童 / 青少年 / 成人三档；默认青少年，影响语气与纠错强度 |
| 词表 | 高频词 L1–L5 分级；原型使用精简演示词库，正式版替换为 Top 500 全量 |
| 入学测 | **默认引导完成**；允许二次确认后跳过，跳过则临时定级并加速对话校准 |
| 视频形态 | 一期以**语音 + AI 形象**为主；视频通话为后续增强 |
| 纠错强度 | 儿童偏软（soft），青少年/成人 balanced |
| 语言 | UI 中文；对话允许中英输入，语伴输出以等级约束的英文为主 |
| 商业模式 | 原型不设付费墙；正式版另议 |

### 9.1 仍待后续确认

1. Top 500 正式词表来源与版权  
2. 真实 LLM / ASR / 文生图 API 选型与成本  
3. 未成年人合规与家长同意流程细节  
4. 订阅或时长限制策略

## 11. 附录：入学测试流程（详细）

### 11.1 流程步骤

1. 说明页：告知「约 10 分钟，用于匹配最适合你的语伴难度」  
2. 音频/权限检查（若含听力/跟读）  
3. 分阶或自适应答题（每题及时正误反馈可配置：建议测中少打扰，测后统一反馈）  
4. 结果页：等级、解读、示例「语伴会这样和你说话」  
5. 进入首次欢迎对话（难度已按结果锁定）  

### 11.2 与后续动态评估的关系

```
入学测 = 冷启动基线（Bootstrap）
交互数据 = 在线校准（Online Calibration）
画像服务 = 唯一难度真相源（Source of Truth）
对话/多模态 = 消费画像约束并回流信号
```

入学测不是一次性标签；当交互数据与入学测结果长期冲突时，以**近期交互证据**为主、入学测为先验，平滑更新，避免等级剧烈跳动。
