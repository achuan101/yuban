# 语伴 · AI 英语陪伴（Vue 网页产品）

基于 `docs/需求文档.md` 实现的 Vue 3 网页原型：入学测定级 → 语音/文字对话 → 难词生图辅助 → 复盘词本与学习画像。

## 技术栈

- Vue 3 + Vite
- Vue Router
- Pinia（本地 localStorage 持久化）

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可。

## 功能地图

| 路径 | 说明 |
|------|------|
| `/` | 品牌欢迎页 |
| `/onboarding` | 基础信息采集 |
| `/placement` | 入学测试（自适应高频词） |
| `/home` | 语伴主页与推荐话题 |
| `/chat` | 语音/文字对话 + 生图浮层 |
| `/review` | 会话复盘与词本 |
| `/me` | 学习画像与策略 |

## 说明

- 对话与生图为**前端演示**：语伴回复为规则/模板生成，生图为 SVG 视觉辅助，不依赖外部大模型 API。
- 语音播报使用浏览器 `speechSynthesis`；语音输入依赖 Web Speech API（Chrome 较佳）。
- 词库为需求中「Top 500 分级」的**精简演示集**，可替换为完整词表服务。
